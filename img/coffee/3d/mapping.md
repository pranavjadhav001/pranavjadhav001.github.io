# Coffee pouch image → ledger mapping

Maps the renamed AI-rendered pouch images in this directory to rows in the
live coffee-beans ledger (fetched from
`https://coffee-beans-proxy.pranavjadhav001.workers.dev/coffee-beans`, which
backs the table/cards on `/coffee/`). The ledger is not a file in this repo —
it's Notion-backed — so this file is the only static record of the pairing.

Filenames follow `<coffee-name-slug>+<roaster-slug>.webp` (no roaster suffix
if none was legible on the pouch). A `-2`/`-3` suffix marks a duplicate
render of the same coffee.
